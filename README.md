# Ритм недели

Личный трекер привычек в тёмно-синей теме: расписание на каждый день недели, отметки выполнения и статистика продуктивности за неделю.

## Возможности

- Панели на каждый день (Пн–Вс), переключение свайпом
- Дела со временем и категорией: учёба, проекты, спорт, здоровье, отдых
- Добавление одного дела сразу в несколько дней, редактирование и удаление
- Анимации: прорисовка галочки, кольца прогресса, конфетти при 100% за день
- Вкладка «Неделя»: % продуктивности, сравнение с прошлой неделей, график по дням, серия дней ≥ 80%, лучший день, разбивка по категориям
- Листание прошлых и будущих недель

## Запуск

Это один файл `index.html` без сборки и зависимостей — просто открой его в браузере.

Чтобы пользоваться с телефона: включи **GitHub Pages** (Settings → Pages → Branch: `main`, папка `/root`), открой полученную ссылку в мобильном браузере и добавь её на главный экран.

Данные хранятся в `localStorage` браузера.
